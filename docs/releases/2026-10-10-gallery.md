# Gallery release

Published separately from the approved scanner-room release (`f840593`).

`/gallery` reconstructs the narrow installation space from Helen's reference image. The room has textured plaster, floor, skirting, ceiling fixtures, canvas depth and three supplied works. Dimensions and lighting are inferred. Six black wall panels preserve the arrangement without inventing missing imagery.

Visitors can drag to look, walk with keyboard/scroll/touch controls, click paintings to approach, choose named viewpoints, and open an enlarged artwork with context. Four supplied viewer drawings are sampled into a luminous projection overlay, with a switch for the unprojected painting. The homepage and thesis Installation tab link to the room.

Navigation keeps visitors within the room and at eye level. Diagonal speed is normalized; turns use the short angle arc. Reduced motion avoids camera travel, hidden tabs suspend rendering, dialogs use native focus behavior, and devices without WebGL retain the installation image and project link.

Validation: navigation tests, Astro check, production build, internal links, script syntax, browser rendering and projection shader compilation, desktop/mobile controls and artwork dialog. The public Cloudflare deployment is checked after the GitHub push.
